## Neste steg - Push til GitHub:

### Metode 1: Via Terminal (hvis du har GitHub autentisering satt opp)

```bash
cd "/Users/emilvisnessilseth/Documents/NEXRA/Nettsider/Panorama Bowling"
git push -u origin main
```

### Metode 2: Via GitHub Desktop (Enklest!)

1. Last ned GitHub Desktop: https://desktop.github.com
2. Logg inn med GitHub-kontoen din
3. Åpne dette prosjektet i GitHub Desktop
4. Klikk "Push origin" knappen

### Metode 3: Via GitHub Web (Alternativ)

Hvis push ikke fungerer, kan du:
1. Gå til: https://github.com/nexracontact/Panorama-Bowling
2. Klikk "uploading an existing file"
3. Dra filene fra mappen din inn

## Etter GitHub push - Koble til Vercel:

1. Gå til https://vercel.com
2. Logg inn
3. Klikk "Add New..." → "Project"
4. Klikk "Import Git Repository"
5. Velg `nexracontact/Panorama-Bowling`
6. Framework: "Other"
7. Klikk "Deploy"

Nettsiden vil være live på Vercel og oppdatere automatisk! 🚀
